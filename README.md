# TURBO KART GP

ブラウザで遊べる3Dカートレースゲームです。描画には [three.js](https://threejs.org/)（r170, MIT License）を使い、`lib/` に同梱しています。画像ファイルやビルドは不要です。

- 8台レース、50cc / 100cc / 150cc の3クラス
- コース2種：「ひだまりサーキット」（丘とジャンプ・3周）、「クロスロード渓谷」（立体交差・トンネル・ジャンプ・2周）
- アイテム13種：ターボ / トリプルターボ / ゴールドターボ / オイル / ニセボックス / バウンドボール / トリプルボール / ホーミング / スカイボム / サンダー / スーパーシールド / ロケットダッシュ / ペイント
- ジャンプ中にドリフトボタンでトリック（着地でミニターボ）
- キャラクター8人（軽量級・中量級・重量級）× カート3種（スタンダード / スピードスター / バギー）から選択。組み合わせで性能が変わります
- ドリフト → ミニターボ（2段階）
- ダッシュパネル、ミニマップ、順位・ラップ・タイム表示
- PC（キーボード）とスマホ（横画面タッチ）の両対応

## 操作

| | PC | スマホ |
|---|---|---|
| アクセル | ↑ / W | 自動 |
| ブレーキ | ↓ / S | ブレーキ |
| ハンドル | ← → / A D | ◀ ▶ |
| ドリフト | Space（曲がりながら押し続け、離すとミニターボ） | ドリフト |
| アイテム | Shift / X | アイテム |
| タイトルへ | Esc | ✕ やめる |

## GitHub Pages で公開する

1. リポジトリを作成し、`index.html` をルートに置いて push
2. Settings → Pages → Branch を `main` / `(root)` にして Save
3. `https://shinopipi.github.io/turbo-cart/` で遊べます

iPhone は Safari の「ホーム画面に追加」でフルスクリーンのアプリとして起動できます。

※ `index.html` をファイルとして直接開くと読み込めません。GitHub Pages か、ローカルなら `python3 -m http.server` などで開いてください。
